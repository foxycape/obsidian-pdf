Программа для чтения PDF в Obsidian. Выделения, цитаты и глубокие ссылки возвращают к месту в тексте, и цепочка к заметке не обрывается. Когда читаешь статью или учебный материал, перевод, поиск слова, объяснение и вопросы остаются в уже открытом PDF.

## Зачем

Чтение PDF в Obsidian часто рвёт путь к заметке:

- Выделение остаётся в PDF, заметка хранилища — в другом месте.
- Рисунок обычно оказывается размытым снимком, с которым неудобно работать.
- Вставленная цитата или картинка редко указывает на точную страницу или область.
- В тёмной теме светлая страница PDF режет глаз.
- Смена программы чтения может сломать уже записанные ссылки на страницу и выделение.

В статье или учебном тексте незнакомое слово, длинное предложение или новое понятие останавливают чтение. Перевод, словарь и вопросы уходят в другой инструмент, а страницу приходится искать самому.

Foxycape PDF закрывает эти пробелы внутри Obsidian.

## Возможности

### Понять статью или учебный текст на текущей странице

#### Статья на другом языке: от беглого просмотра к чтению

Выделите фрагмент — он переводится, и сначала виден смысл. По умолчанию это перевод Microsoft; беглый просмотр не тратит использование ИИ. Если формулировка должна быть ближе к предмету, переключитесь на ИИ, выберите **Сначала скорость** или **Сначала качество** и язык перевода.

Если в этом фрагменте слово всё ещё неясно, нажмите **Найти слово**. Произношение даётся в МФА, пиньине или кане, вместе со значением в этом месте. Если выделено целое предложение, сначала идёт смысл предложения, потом трудные слова.

Если фрагмент по-прежнему неясен, **Объяснить фрагмент** раскрывает только этот кусок, чтобы читать дальше. **Кратко** — одно-два предложения — достаточно, чтобы перевернуть страницу. Чтобы развернуть, выберите **Подробно**. **Подробнее** отправляет фрагмент и уже показанное объяснение в боковую панель **Спросить ИИ**.

Переводы, объяснения и найденные слова остаются в списке этого PDF. Их можно отфильтровать и вернуться на страницу. Чтобы записать их в заметку, включите запись каждого вида в настройках (по умолчанию выключено). Они дописываются в Markdown с тем же именем, что и PDF.

#### Читать длинный текст и спрашивать по ходу

Выделите фрагмент и спросите ИИ. Вопрос берёт с собой этот текст. Если документ длинный, Foxycape сначала спрашивает, анализировать ли его. Если согласиться, ответ опирается на фрагменты документа, а цитата открывает страницу. Если отказаться, ответ идёт из общих знаний. Позже в меню можно выбрать **Анализировать эту книгу**.

Когда цитата возвращает на страницу, а фрагмент всё ещё неясен, перевод, поиск слова и объяснение остаются под рукой. После ответа появляются связанные вопросы, по которым можно продолжить. Разговоры хранятся вместе с этим PDF: их можно искать или начать новый.

### Модель и использование

Объяснение, поиск слова, перевод ИИ и вопросы используют выбранную модель. Расход официальной модели учитывается в использовании ИИ по лицензии. Можно указать свой **базовый URL** и **ключ API**. Перевод Microsoft этот расход не тратит. Лицензию можно получить бесплатно. Использование можно купить или получить, поделившись.

### Выделение в заметку

Выделению не обязательно оставаться только в PDF. Новое может создать или обновить заметку Markdown с тем же именем, дописать отрывок с обратной ссылкой и при желании открыть эту заметку в разделённой панели. Это отключается в настройках.

### Цитировать текст и изображения и возвращаться к источнику

Цитата хранит происхождение, и из заметки можно вернуться в PDF:

- Скопировать текстовую цитату как Markdown с глубокой ссылкой (`#page=` / `#selection=` / `#markId=`).
- Скопировать цитату изображения. Вставка в Markdown сохраняет PNG рядом с PDF и вставляет ссылку.
- Правый щелчок по изображению в заметке → **Открыть в Foxycape**: возврат на страницу и подсветка исходной области.

![](docs/gifs/cite-and-back.gif)

## Разработка

```bash
npm install
npm run build      # → dist/main.js, styles.css, manifest.json, versions.json, markdown.js, pdfjs.zip, reader-bundle.zip, locales.zip, pdfjs-assets.zip
npm run dev        # сборка с наблюдением; после успеха копирует в OBSIDIAN_PLUGIN_DIR
npm test
npm run typecheck
npm run link       # junction dist/ в .obsidian/plugins/foxycape-pdf хранилища
```

Задайте `OBSIDIAN_PLUGIN_DIR` в `.env` (см. `.env.example`). `npm run dev` копирует результат туда после каждой успешной сборки; `npm run link` читает ту же переменную и, если её нет, использует путь хранилища по умолчанию. Переменная окружения процесса важнее файла.
