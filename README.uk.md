Програма для читання PDF в Obsidian. Виділення, цитати й глибокі посилання повертають до місця в тексті, і ланцюжок до нотатки не обривається. Коли читаєш статтю чи навчальний матеріал, переклад, пошук слова, пояснення і запитання лишаються у вже відкритому PDF.

## Навіщо

Читання PDF в Obsidian часто рве шлях до нотатки:

- Виділення лишається в PDF, нотатка сховища — деінде.
- Малюнок зазвичай стає розмитим знімком, з яким незручно працювати.
- Вставлена цитата чи зображення рідко вказують на точну сторінку або ділянку.
- У темній темі світла сторінка PDF ріже око.
- Зміна програми читання може зламати вже записані посилання на сторінку й виділення.

У статті чи навчальному тексті незнайоме слово, довге речення або нове поняття зупиняють читання. Переклад, словник і запитання йдуть в інший інструмент, а сторінку доводиться шукати самому.

Foxycape PDF закриває ці прогалини всередині Obsidian.

## Можливості

### Зрозуміти статтю чи навчальний текст на поточній сторінці

#### Стаття іншою мовою: від побіжного перегляду до читання

Виділіть уривок — його перекладено, і спершу видно зміст. Типово це переклад Microsoft; побіжний перегляд не витрачає використання ШІ. Якщо формулювання має бути ближчим до предмета, перемкніться на ШІ, оберіть **Спочатку швидкість** або **Спочатку якість** і мову перекладу.

Якщо в цьому уривку слово досі неясне, натисніть **Знайти слово**. Вимову подано в МФА, піньїні або кана, разом зі значенням у цьому місці. Якщо виділено ціле речення, спершу йде зміст речення, потім складні слова.

Якщо уривок і далі неясний, **Пояснити уривок** розкриває лише цей шматок, щоб читати далі. **Стисло** — одне-два речення — досить, щоб перегорнути сторінку. Щоб розгорнути, оберіть **Докладно**. **Докладніше** надсилає уривок і вже показане пояснення в бічну панель **Запитати ШІ**.

Переклади, пояснення і знайдені слова лишаються в списку цього PDF. Їх можна відфільтрувати і повернутися на сторінку. Щоб записати їх у нотатку, увімкніть запис кожного виду в налаштуваннях (типово вимкнено). Їх дописують у Markdown з тією самою назвою, що й PDF.

#### Читати довгий текст і питати по ходу

Виділіть уривок і запитайте ШІ. Запитання бере із собою цей текст. Якщо документ довгий, Foxycape спершу питає, чи аналізувати його. Якщо погодитися, відповідь спирається на уривки документа, а цитата відкриває сторінку. Якщо відмовитися, відповідь іде із загальних знань. Пізніше в меню можна обрати **Аналізувати цю книгу**.

Коли цитата повертає на сторінку, а уривок досі неясний, переклад, пошук слова і пояснення лишаються під рукою. Після відповіді з’являються пов’язані запитання, якими можна продовжити. Розмови зберігаються разом із цим PDF: їх можна шукати або почати нову.

### Модель і використання

Пояснення, пошук слова, переклад ШІ і запитання використовують обрану модель. Витрата офіційної моделі враховується у використанні ШІ за ліцензією. Можна вказати свій **базовий URL** і **ключ API**. Переклад Microsoft цю витрату не чіпає. Ліцензію можна отримати безкоштовно. Використання можна купити або отримати, поділившись.

### Виділення в нотатку

Виділенню не обов’язково лишатися лише в PDF. Нове може створити або оновити нотатку Markdown з тією самою назвою, дописати уривок зі зворотним посиланням і за бажання відкрити цю нотатку в розділеній панелі. Це вимикається в налаштуваннях.

### Цитувати текст і зображення та повертатися до джерела

Цитата зберігає походження, і з нотатки можна повернутися в PDF:

- Скопіювати текстову цитату як Markdown із глибоким посиланням (`#page=` / `#selection=` / `#markId=`).
- Скопіювати цитату зображення. Вставлення в Markdown зберігає PNG поруч із PDF і вставляє посилання.
- Правий клік по зображенню в нотатці → **Відкрити у Foxycape**: повернення на сторінку і підсвічування вихідної ділянки.

## Розробка

```bash
npm install
npm run build      # → dist/main.js, styles.css, manifest.json, versions.json, markdown.js, pdfjs.zip, reader-bundle.zip, locales.zip, pdfjs-assets.zip
npm run dev        # збирання зі спостереженням; після успіху копіює в OBSIDIAN_PLUGIN_DIR
npm test
npm run typecheck
npm run link       # junction dist/ у .obsidian/plugins/foxycape-pdf сховища
```

Задайте `OBSIDIAN_PLUGIN_DIR` у `.env` (див. `.env.example`). `npm run dev` копіює результат туди після кожного успішного збирання; `npm run link` читає ту саму змінну і, якщо її немає, використовує шлях сховища за замовчуванням. Змінна середовища процесу важливіша за файл.
