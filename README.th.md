## ทำไมต้องมี

การอ่าน PDF ใน Obsidian มักทำให้ทางไปถึงบันทึกขาด:

- ไฮไลต์ค้างอยู่ใน PDF บันทึกในคลังอยู่คนละที่
- อยากได้รูป มักได้แต่ภาพจอที่เบลอและจัดการยาก
- ข้อความหรือรูปที่วางไว้ ไม่ค่อยชี้กลับไปยังหน้าหรือบริเวณที่ตรง
- ในธีมมืด หน้า PDF สีอ่อนแสบตา
- เปลี่ยนโปรแกรมอ่านแล้ว ลิงก์หน้าและช่วงที่เลือกไว้อาจใช้ไม่ได้

ในบทความหรือเอกสารเรียน คำที่ไม่รู้จัก ประโยคยาว หรือแนวคิดที่ไม่คุ้น ทำให้การอ่านหยุด การแปล พจนานุกรม และคำถามต้องย้ายไปเครื่องมืออื่น แล้วต้องจับเลขหน้าเอง

Foxycape PDF อุดช่องเหล่านี้ภายใน Obsidian

## ความสามารถ

### อ่านบทความหรือเอกสารเรียนให้เข้าใจบนหน้าที่เปิดอยู่

#### บทความภาษาต่างประเทศ จากการกวาดตาไปจนอ่านรู้เรื่อง

เลือกช่วงหนึ่งแล้วแปลได้ทันที ได้ใจความก่อน ค่าเริ่มต้นคือการแปลของ Microsoft การกวาดตาไม่ใช้การใช้ AI หากอยากให้ถ้อยคำใกล้สาขามากขึ้น ให้สลับเป็น AI แล้วเลือก **ความเร็วก่อน** หรือ **คุณภาพก่อน** และภาษาปลายทาง

ถ้าในย่อหน้านั้นยังมีคำที่ไม่มั่นใจ ให้ใช้ **ค้นหาคำ** การออกเสียงแสดงด้วยสัทอักษรสากล พินอิน หรือคะนะ พร้อมความหมายในย่อหน้านี้ ถ้าเลือกทั้งประโยค จะได้ความหมายของประโยคก่อน แล้วจึงชี้คำยาก

ถ้าย่อหน้านั้นยังอ่านไม่รู้เรื่อง **อธิบายช่วงนี้** จะคลี่เฉพาะช่วงนั้น เพื่ออ่านต่อได้ **ย่อ** สักหนึ่งถึงสองประโยค ก็พอจะพลิกหน้าต่อ เมื่ออยากขยาย ให้เลือก **ละเอียด** **เรียนรู้เพิ่มเติม** ส่งข้อความเดิมและคำอธิบายที่มีอยู่ไปยังแผงข้างของ **ถาม AI**

คำแปล คำอธิบาย และการค้นคำอยู่ในรายการของ PDF นี้ กรองได้ และกระโดดกลับไปหน้านั้น เมื่ออยากจดลงบันทึก ให้เปิดการเขียนของแต่ละชนิดในการตั้งค่า (ค่าเริ่มต้นปิด) ระบบจะต่อท้ายไฟล์ Markdown ที่ชื่อเดียวกับ PDF

<!-- GIF: docs/gifs/read-in-place.gif — เลือกแล้วแปล ค้นคำ อธิบาย -->

#### อ่านเอกสารยาวไปพร้อมกับถาม

เลือกช่วงหนึ่งแล้วถาม AI ได้เลย คำถามพกข้อความนั้นไปด้วย ถ้าเอกสารยาว Foxycape จะถามก่อนว่าจะวิเคราะห์เอกสารนี้หรือไม่ ถ้าตกลง คำตอบอิงย่อหน้าในเอกสาร และการอ้างอิงเปิดหน้านั้นได้ ถ้าไม่ตกลง จะตอบตามความรู้ทั่วไป ภายหลังยังเลือก **วิเคราะห์หนังสือเล่มนี้** จากเมนูได้

เมื่อการอ้างอิงพากลับมาที่หน้าหนึ่ง แล้วย่อหน้านั้นยังไม่เข้าใจ การแปล การค้นคำ และการอธิบายยังใช้ต่อได้ ตอบเสร็จจะมีคำถามที่เกี่ยวข้องให้กดต่อ บทสนทนาถูกเก็บตาม PDF นี้ เปิดครั้งหน้ายังค้นได้ หรือเริ่มบทสนทนาใหม่

<!-- GIF: docs/gifs/ask-while-reading.gif — ถาม PDF ที่เปิดอยู่ แล้วกระโดดกลับจากคำอ้างอิง -->

### โมเดลและการใช้ AI

การอธิบาย การค้นคำ การแปลด้วย AI และการถาม AI ใช้โมเดลที่เลือกอยู่ การใช้โมเดลทางการนับเข้าการใช้ AI ของใบอนุญาต จะกรอก **URL หลัก** และ **คีย์ API** ของตัวเองก็ได้ การแปลของ Microsoft ไม่นับการใช้ส่วนนี้ ใบอนุญาตรับได้ฟรี การใช้ AI ซื้อได้ หรือได้จากการแชร์

### อ้างอิงข้อความและรูป แล้วกลับไปต้นทาง

การอ้างอิงมีที่มา จากบันทึกกระโดดกลับไป PDF ได้:

- คัดลอกการอ้างอิงข้อความเป็น Markdown พร้อมลิงก์ลึก (`#page=` / `#selection=` / `#markId=`)
- คัดลอกการอ้างอิงรูป วางใน Markdown แล้วจะบันทึก PNG ข้าง PDF และใส่ลิงก์ที่กดได้
- คลิกขวาที่รูปในบันทึก → **เปิดใน Foxycape** กลับไปหน้าที่ตรงและเน้นบริเวณเดิม

## พัฒนา

```bash
npm install
npm run build      # → dist/main.js, styles.css, manifest.json, versions.json, markdown.js, pdfjs.zip, reader-bundle.zip, locales.zip, pdfjs-assets.zip
npm run dev        # บิลด์แบบเฝ้าดู ถ้าตั้ง OBSIDIAN_PLUGIN_DIR ไว้ จะคัดลอกไปโฟลเดอร์ปลั๊กอินนั้นเมื่อสำเร็จ
npm test
npm run typecheck
npm run link       # junction ของ dist/ ไปที่ .obsidian/plugins/foxycape-pdf ในคลัง
```

ตั้ง `OBSIDIAN_PLUGIN_DIR` ใน `.env` (ดู `.env.example`) แล้ว `npm run dev` จะคัดลอกผลลัพธ์ไปที่นั่นทุกครั้งที่บิลด์สำเร็จ `npm run link` อ่านตัวแปรเดียวกัน ถ้าไม่ได้ตั้งจะใช้เส้นทางคลังเริ่มต้น ตัวแปรสภาพแวดล้อมของโปรเซสสำคัญกว่าไฟล์
