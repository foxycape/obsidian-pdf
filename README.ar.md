## لماذا

قراءة PDF داخل Obsidian تقطع كثيرًا الطريق إلى الملاحظة:

- التظليل يبقى في PDF، وملاحظة الخزنة في مكان آخر.
- الحصول على شكل يعني غالبًا لقطة ضبابية يصعب ترتيبها.
- الاقتباس أو الصورة الملصقة نادرًا ما يشيران إلى الصفحة أو المنطقة بدقة.
- في السمة الداكنة، صفحة PDF الفاتحة تؤذي العين.
- تغيير القارئ قد يُبطل روابط الصفحة والتحديد المكتوبة من قبل.

في بحث أو مادة دراسية، كلمة غير مألوفة أو جملة طويلة أو مفهوم جديد يوقف القراءة. الترجمة والقاموس والأسئلة تنتقل إلى أداة أخرى، وعلى القارئ أن يطابق رقم الصفحة بنفسه.

Foxycape PDF يسد هذه الفجوات داخل Obsidian.

## الوظائف

### فهم بحث أو مادة دراسية على الصفحة الحالية

#### بحث بلغة أخرى، من مرور سريع إلى قراءة مفهومة

تحديد فقرة يترجمها ويُظهر المعنى أولًا. الترجمة الافتراضية من Microsoft، والمرور السريع لا يستهلك استخدام الذكاء الاصطناعي. للاقتراب من صياغة التخصص، انتقل إلى الذكاء الاصطناعي، واختر **السرعة أولًا** أو **الجودة أولًا**، ثم لغة الهدف.

إذا بقيت كلمة في هذه الفقرة غير واضحة، استخدم **ابحث عن الكلمة**. يُعرض النطق بالأبجدية الصوتية الدولية أو البينيين أو الكانا، مع المعنى في هذا الموضع. إذا كان التحديد جملة كاملة، يأتي معنى الجملة أولًا ثم الكلمات الصعبة.

إذا بقيت الفقرة غير مفهومة، يفتح **اشرح هذه الفقرة** هذا المقطع فقط حتى تستمر القراءة. **موجز**، جملة أو جملتان، يكفي لقلب الصفحة. للمزيد اختر **مفصّل**. **معرفة المزيد** يرسل الفقرة والشرح الظاهر إلى اللوحة الجانبية **اسأل الذكاء الاصطناعي**.

تبقى الترجمات والشروح وعمليات البحث عن الكلمات في قائمة هذا الـ PDF. يمكن تصفيتها والعودة إلى الصفحة. لتدوينها في الملاحظة، فعّل الكتابة لكل نوع في الإعدادات (مغلقة افتراضيًا). تُلحَق بملف Markdown الذي يحمل اسم الـ PDF نفسه.

<!-- GIF: docs/gifs/read-in-place.gif — تحديد ثم ترجمة وبحث وشرح -->

#### قراءة نص طويل والسؤال أثناء ذلك

حدّد فقرة واسأل الذكاء الاصطناعي. السؤال يحمل هذا النص. إذا كان المستند طويلًا، يسأل Foxycape أولًا هل يُحلَّل. عند الموافقة يستند الجواب إلى فقرات المستند، والاقتباس يفتح الصفحة. عند الرفض يأتي الجواب من معرفة عامة. لاحقًا يمكن اختيار **تحليل هذا الكتاب** من القائمة.

عند العودة إلى صفحة عبر اقتباس، إذا بقيت تلك الفقرة غير واضحة، تبقى الترجمة والبحث والشرح متاحة. بعد الجواب تظهر أسئلة مرتبطة للمتابعة. تُحفظ المحادثات مع هذا الـ PDF، ويمكن البحث فيها أو بدء محادثة جديدة.

<!-- GIF: docs/gifs/ask-while-reading.gif — السؤال عن PDF المفتوح والعودة إلى الصفحة -->

### النموذج والاستخدام

الشرح والبحث وترجمة الذكاء الاصطناعي والأسئلة تستخدم النموذج المختار. يُحسب استخدام النموذج الرسمي على استخدام الذكاء الاصطناعي في الترخيص. يمكن أيضًا إدخال **عنوان URL الأساسي** و**مفتاح API** الخاصين بك. ترجمة Microsoft لا تستهلك هذا الاستخدام. يمكن الحصول على الترخيص مجانًا. ويمكن شراء الاستخدام أو الحصول عليه بالمشاركة.

### التظليل إلى الملاحظة

ليس على التظليل أن يبقى داخل PDF وحده. تظليل جديد يمكنه إنشاء ملاحظة Markdown بالاسم نفسه أو تحديثها، وإلحاق المقتطف مع رابط للعودة، وفتح تلك الملاحظة في لوحة مقسومة عند الحاجة. يُوقف ذلك من الإعدادات.

### اقتباس النص والصور ثم العودة إلى المصدر

الاقتباس يحتفظ بالمصدر، ومن الملاحظة يمكن الرجوع إلى PDF:

- انسخ اقتباس النص كـ Markdown مع رابط عميق (`#page=` / `#selection=` / `#markId=`).
- انسخ اقتباس الصورة. لصقه في Markdown يحفظ PNG بجانب الـ PDF ويدرج رابطًا.
- انقر بزر الفأرة الأيمن على الصورة في الملاحظة → **فتح في Foxycape**، للعودة إلى الصفحة وإبراز المنطقة الأصلية.

## التطوير

```bash
npm install
npm run build      # → dist/main.js, styles.css, manifest.json, versions.json, markdown.js, pdfjs.zip, reader-bundle.zip, locales.zip, pdfjs-assets.zip
npm run dev        # بناء مع المراقبة؛ ينسخ إلى OBSIDIAN_PLUGIN_DIR بعد كل نجاح
npm test
npm run typecheck
npm run link       # junction من dist/ إلى .obsidian/plugins/foxycape-pdf في الخزنة
```

اضبط `OBSIDIAN_PLUGIN_DIR` في `.env` (انظر `.env.example`). ينسخ `npm run dev` الناتج إلى هناك بعد كل بناء ناجح؛ ويقرأ `npm run link` المتغير نفسه، وإن لم يُضبط يستخدم مسار الخزنة الافتراضي. متغير بيئة العملية يغلب الملف.
