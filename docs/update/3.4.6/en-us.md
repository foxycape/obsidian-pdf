# Foxycape PDF 3.4.6

Scanned pages, equations, and tables often cannot be selected as text. I used to screenshot them and switch to another tool.
This update adds screenshot recognition. Box a region in the PDF and turn it into text, an equation, or a table, then copy it into a note. If the result looks fine, use it as is. Proofreading can push accuracy above 99% when you want a second look.
